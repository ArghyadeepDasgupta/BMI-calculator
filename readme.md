# BMI Calculator

A simple and interactive Body Mass Index (BMI) calculator built with HTML, CSS, and JavaScript.

## Features
- Calculates BMI from height (cm) and weight (kg) with input validation
- Highlights the matching BMI category (`Underweight`, `Healthy Weight`, `Overweight`, `Obesity`) dynamically
- Supports pressing `Enter` to calculate
- Individual reset buttons for height and weight that restore the default output state
- Glassmorphism UI with smooth CSS transitions

## Tech Stack
- HTML5
- CSS3
- JavaScript (ES6+)
